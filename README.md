# Zenith
## Projeto de gestão e organização financeira

O presente projeto propõe uma nova abordagem para o gerenciamento de finanças pessoais. A proposta surgiu a partir
da dificuldade em encontrar soluções gratuitas e eficientes no mercado atual, onde os aplicativos disponíveis 
limitam-se a gerenciar uma parcela superficial da vida financeira do usuário, retendo ferramentas cruciais sob 
modelos pagos. Por este motivo, foi desenvolvido a Zenith, um app de gestão financeira 100% gratuito, que gere 
de forma completa e integral os dados financeiros. Em nosso projeto, criamos páginas que disponibilizam um 
CRUD( Atualização, Exclusão, Criação e Listagem) completo de Gastos, Ganhos, Investimentos, Cartões, Perfil de
 usuário e Reserva de emergência, além de uma página Home voltada para a visualização dos dados através de 
 gráficos e cards. Também, possuimos páginas de Login, Esqueceu Senha e Registro visando maior segurança e 
 confiabilidade.
